**SYNAPSE-1024：面向数字生命的仿生可移植心智开源架构 V5.0 实现**

分层风化记忆、陈述/程序性双记忆、内分泌情绪调制、`.lifecard` 生命卡热插拔；包含防污染元认知层、Dream 梦境压缩机制；心智逻辑与大模型通道解耦。

**本版内容**
- 记忆：五层（骨头 / 标签 / 底色 / 中期 / 短期）× 五池，短期数小时、中期按天、长期按年衰减，只有物理只读层不动
- 完整性：写入时封存原文 sha256 出生证、删除留台账、身份锚只覆盖不变量 —— "她是不是假装记得"可被审计
- 安全：防污染元认知层（规则化信任评分 + 冲突标记，低信任降权且不得晋升）
- 长期会话：Dream 两段式压缩（卡侧掏原文 / 标记已消化，提炼交给宿主模型，原文永不删）
- 情绪：四激素调制 + PAD 三维投影（公式单一实现，控制台历史曲线现算不落库）
- 可移植：单文件 SQLite，插卡 / 拔卡与通道彻底解耦
- 评估：22 条用例（召回 / 证据 / 攻击 / 正常），R@1 75.0%、R@3 100%、证据命中 100%、注入识别 100%、误报 0%
